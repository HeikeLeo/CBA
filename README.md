<h1>CBA赛程</h1>
<h2>简介</h2>
本网站会有一个表格显示近期的CBA赛程。
<br><br>
<b>赛程数据是由人工通过爬虫获取后上传至本网站的，数据可能会出现错误或延迟</b>
<h2>功能</h2>
<ul>
  <li>本网站有高亮关键赛程功能，当鼠标在赛程上悬浮时该赛程会高亮土黄色，鼠标离开后复原；当天的赛程会高亮粉红色；主队或客队含有广东、广州和深圳这三支球队，该赛程会高亮天蓝色；主队或客队含有广东、广州和深圳这三支球队，且该赛程为当天的赛程会高亮金色</li>
  <li>本网站页尾若显示“点击显示往期赛程”按钮，点击后在按钮后方会显示往期的赛程，再次点击按钮可隐藏</li>
</ul>
